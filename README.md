# قالب منيو المقاهي

قالب عربي خفيف لمنيو مقهى إلكتروني، يعمل كملفات ثابتة في المتصفح. لا يحتوي على سلة أو طلبات أو دفع أو قاعدة بيانات أو خادم.

## تغيير بيانات المقهى

عدّل الملف `cafe-config.js`:

- غيّر `name` و`brandName` و`brandDescriptor` لاسم المقهى الظاهر في الصفحة.
- غيّر `logo` إلى مسار صورة الشعار، أو اتركه فارغًا لاستخدام رمز القهوة الافتراضي. حدّث النصوص داخل `header` للشعار والوصف والعناوين.
- أضف رقم الهاتف بصيغة دولية، ورقم واتساب مع رمز الدولة، وروابط حسابات إنستغرام وتيك توك وسناب شات وخرائط Google.
- اكتب العنوان وأوقات العمل. اترك أي معلومة غير متوفرة نصًا فارغًا؛ تبقى أسماء واتساب وإنستغرام وتيك توك وسناب شات ظاهرة كخانات غير قابلة للنقر إلى أن تضيف روابطها.
- غيّر القيم داخل `colors` لتخصيص ألوان الهوية. استخدم رموز الألوان بصيغة `#RRGGBB`.

## تعديل الأصناف والصور والأسعار

تُحمّل القائمة من ملف Google Sheets المنشور بصيغة CSV. عدّل الجدول ثم انشره عبر **File > Share > Publish to web** بصيغة CSV. يجب أن يتضمن الصف الأول الأعمدة التالية:

- `id`: معرّف الصنف.
- `name`: اسم المشروب.
- `price`: السعر بالريال.
- `category`: استخدم `hot` للساخن أو `cold` للبارد.
- `image`: رابط أو مسار الصورة؛ يمكن تركه فارغًا لعرض الكرت دون صورة.
- `available`: اكتب `yes` لعرض الصنف أو `no` لإخفائه.

تُحدّث الأصناف المنشورة تلقائيًا عند فتح الصفحة. لا تحتاج إلى تعديل `app.js` لتحديث بيانات الجدول.

## التشغيل والنشر على Cloudflare Pages

يمكن فتح `index.html` مباشرة أو رفع ملفات المشروع إلى مستودع Git. في Cloudflare Pages اختر المستودع، واترك أمر البناء ومجلد الإخراج فارغين أو استخدم مجلد المشروع كجذر؛ فالموقع يتكوّن من ملفات ثابتة ولا يحتاج إلى عملية بناء. بعد النشر، استخدم رابط الموقع لإنشاء رمز QR.
