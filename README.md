# Plant Leaf | المنيو الإلكتروني

منيو Plant Leaf الإلكتروني، يعمل كملفات ثابتة في المتصفح. لا يحتوي على سلة أو طلبات أو دفع أو قاعدة بيانات أو خادم.

## التشغيل المحلي

افتح `index.html` في المتصفح، أو شغّل خادم ملفات محليًا من مجلد المشروع:

```powershell
py -m http.server 8000
```

ثم افتح `http://localhost:8000`. لا يحتاج المشروع إلى `npm install` أو أمر بناء.

## تغيير بيانات المقهى

عدّل الملف `cafe-config.js`:

- غيّر `name` و`brandName` و`brandDescriptor` لاسم المقهى الظاهر في الصفحة.
- غيّر `logo` إلى مسار صورة الشعار، أو اتركه فارغًا لاستخدام رمز القهوة الافتراضي. حدّث النصوص داخل `header` للشعار والوصف والعناوين.
- أضف رقم الهاتف بصيغة دولية، ورقم واتساب مع رمز الدولة، وروابط حسابات إنستغرام وتيك توك وسناب شات وخرائط Google.
- اكتب العنوان وأوقات العمل. اترك أي معلومة غير متوفرة نصًا فارغًا؛ تبقى أسماء واتساب وإنستغرام وتيك توك وسناب شات ظاهرة كخانات غير قابلة للنقر إلى أن تضيف روابطها.
- غيّر القيم داخل `colors` لتخصيص ألوان الهوية. استخدم رموز الألوان بصيغة `#RRGGBB`.

## تعديل الأصناف والصور والأسعار

تُحمّل القائمة من ملف Google Sheets المنشور بصيغة CSV. عدّل الجدول ثم انشره عبر **File > Share > Publish to web** بصيغة CSV. يجب أن يتضمن الصف الأول الأعمدة التالية:

- `id`: معرّف الصنف.
- `name`: اسم المشروب.
- `price`: السعر بالريال كرقم (مثال `12.5`). تُقبل أيضاً عناوين `السعر` أو `سعر`، والأرقام العشرية وفواصل الآلاف وعلامات العملة الشائعة.
- `category`: استخدم `hot` للساخن أو `cold` للبارد أو `desserts` للحلويات أو `breakfast` للفطور. يتعرف قسم الفطور أيضًا على `الفطور` و`فطور`، وقسم الحلويات على `الحلويات` و`حلويات` و`حلى` دون اعتبار للمسافات الزائدة.
- `image`: رابط أو مسار الصورة نسبةً إلى جذر المشروع، مثل `images/drink.jpg`؛ يمكن تركه فارغًا لعرض الكرت دون صورة. عند استخدام مسار محلي، ارفع الملف إلى Git بالاسم وحالة الأحرف نفسيهما لأن Cloudflare Pages يميز بين الأحرف الكبيرة والصغيرة ولا ينشر الملفات غير المتتبعة.
- `available`: اكتب `yes` لعرض الصنف أو `no` لإخفائه.
- `is_offer` (اختياري): اكتب `yes` أو `نعم` أو `true` أو `1` لتحديد الصنف كعرض اليوم.
- `offer_price` (اختياري): سعر العرض؛ يظهر الزر فقط عند وجود صنف محدد كعرض وسعر عرض صالح. يمكن استخدام `عرض_اليوم` و`سعر_العرض` بدلاً من اسمي العمودين الإنجليزيين.

تأكد أن عمود `price` يحتوي أرقام الأسعار فعلاً لا أسماء الأصناف، ثم أعد نشر الورقة بصيغة CSV بعد تعديلها. تُحدّث الأصناف المنشورة تلقائيًا عند فتح الصفحة. لا تحتاج إلى تعديل `app.js` لتحديث بيانات الجدول. ملف `products.js` غير محمّل في الصفحة؛ مصدر القائمة الفعلي هو جدول Google Sheets المنشور.

## النشر على GitHub وCloudflare Pages

ارفع ملفات المشروع إلى مستودع GitHub. لنشر الموقع من خلال Cloudflare Pages، اربط المستودع واختر مجلد المشروع كـ **Root directory**، واترك **Build command** فارغًا، واجعل **Build output directory** هو `.` (جذر المستودع). لا يحتاج المشروع إلى إعداد Cloudflare خاص أو عملية بناء. بعد النشر، استخدم رابط الموقع لإنشاء رمز QR.
